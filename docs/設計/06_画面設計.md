# 助成金管理システム 画面設計

## 1. この文書について

要件定義書の内容を画面単位に整理し、画面ごとの要素・操作・権限を定義します。

- 文書状態: 初版
- 作成日: 2026-09-04
- 前提文書: `01_要件定義.md`、`04_DB論理設計.md`、`11_ステータスの遷移.drawio`
- 画面遷移: `12_画面遷移図.drawio`

## 2. 共通仕様

すべての画面に適用します。各画面の記述では繰り返しません。

### 2.1 レイアウト

- PC とスマートフォンの両方に対応するレスポンシブとし、専用アプリは作りません（5.18）
- 対応ブラウザは Chrome・Edge・Safari の各最新版（5.18）
- ヘッダにベルアイコンを置き、未読通知の件数をバッジ表示します（5.13）
- **お知らせバナーはログイン画面を含むすべての画面に表示**します（5.23）
  - 同時に表示できるのは1件
  - 利用者は閉じられるが、状態は保存せず再読み込みで再表示されます
  - 内部のリンクは新しいタブを開かず現在のタブで開きます

### 2.2 一覧画面の共通仕様

会社一覧・アカウント一覧・申請案件一覧に共通します（5.3, 5.4, 5.14）。

- 1ページ50件のページング
- 列見出しを選択して並び替え
- 初期表示順は各画面の定義に従う

### 2.3 処理中と失敗時の挙動（5.22）

- 保存・PDF生成・ファイルアップロード中は、進捗率を示さないプログレススピナーを表示します
- スピナー表示中は、同じ操作を含む他の操作を行えません
- 失敗した場合はエラーメッセージを表示し、利用者が再実行できるようにします
- 最大50MBのアップロードでも進捗率は表示しません

### 2.4 削除操作

会社・アカウント・申請案件の削除は物理削除で、復元できません。

- 実行前に確認ダイアログを表示します
- 削除理由の入力は求めません
- 削除履歴（G-04）に記録が残ります

### 2.5 ファイルのアップロード

- 形式は PDF・JPEG・PNG、1ファイル最大50MB（5.2）
- ブラウザから S3 へ署名付きURLで直接アップロードします（`03_技術選定.md` 4.6）
- 差し替え時は前のファイルを保持しません

## 6. 主要画面の詳細

### A-01 ログイン

- 入力はログインIDとパスワード
- **ログインIDは大文字小文字を区別**します（5.4）
- 多要素認証は行わず、ログイン失敗が連続してもアカウントをロックしません（5.4）
- 送信元IPアドレス単位のレート制限を AWS WAF で適用します（100回/5分。`03_技術選定.md` 5.4）
- お知らせバナーを表示します（5.23）

### A-02 初回パスワード設定

仮パスワードでログインした場合に必ず経由します。設定するまで他の機能を利用できません（5.4）。

- 新しいパスワードを確認用を含めて2回入力
- 8文字以上20文字以下、半角英字と半角数字をそれぞれ1文字以上、半角記号は任意
- 条件を満たさない場合はその内容を画面に表示し、設定を受け付けません
- 現在または過去に使用したパスワードの再利用を許可します

### B-01 ダッシュボード

- ステータスごとの案件数を表示します（5.14）
- 件数を選択すると、そのステータスで絞り込んだ C-01 へ遷移します
- 社労士には同じ内容を閲覧専用で表示します

ステータスは24段階あるため、**業務フェーズ単位で集計して表示**します。
フェーズを選択すると、内訳のステータスと件数を展開できます。

| フェーズ | ステータス |
| --- | --- |
| 営業 | 1 営業中 〜 3 助成金説明済 |
| 契約 | 4 契約書送付済 〜 5 契約締結済 |
| 受入準備 | 6 必要事項記入中 〜 8 雇用契約書提出済 |
| 案件準備 | 9 日程調整済 〜 10 カリキュラム選定済 |
| 見積 | 11 見積もり兼発注書送付済 〜 12 見積もり兼発注書受領済 |
| 助成金申請手続き | 13 GBiz案内済 〜 14 GBiz記入済 |
| 請求・計画届・入金 | 15 請求書送付済 〜 17 入金確認済 |
| 研修 | 18 研修中 〜 19 研修完了 |
| 支給申請 | 20 支給申請連絡済 〜 23 助成金の支給申請完了 |
| 完了 | 24 完了 |

25 問い合わせ は完了からの往復のため、独立した項目として表示します。
フェーズの区切りは `11_ステータスの遷移.drawio` と一致させています。

### C-01 申請案件一覧

| 項目 | 内容 |
| --- | --- |
| 表示列 | 案件番号・会社名・案件名・主担当事務員・現在のステータス・最終更新日時 |
| 検索 | 会社名、案件番号、案件名 |
| 絞り込み | ステータス、主担当事務員 |
| 初期表示順 | 案件番号の降順 |

範囲はアクターにより異なります。クライアントは自社、代理店は紹介先の会社のみです。

### C-09 申請案件の作成

- **営業を開始した時点で作成します。** 初期ステータスは「営業中」です（5.15）
- 会社を先に作成し、その会社に紐づけて案件を作成します
- 案件番号は作成時に自動発行します
- 案件名と主担当事務員（有効な事務員）は必須です

### C-02 案件詳細 / 基本情報タブ

- 案件番号（自動発行・編集不可）、案件名、会社、主担当事務員、現在のステータス
- 最終更新日時と最終更新者を表示します。システムによる更新は「システム」と表示します（5.17）
- 作成日時と作成者も保持します
- **ステータスを次へ進める操作**を配置します
  - 進めるのは事務員（誤操作時のみ管理者が修正）
  - 順序どおりにのみ進み、戻す・飛ばすことはできません
  - 例外として「完了」と「問い合わせ」は双方向に変更できます
  - 進められない場合は理由を画面に表示します（未入力項目、受講者未登録など／5.3）
- **GBiz案内済・GBiz記入済・計画届済・支給申請連絡済は、ステータスを進める操作だけを行います。**
  GビズIDや提出日などの補足情報、書類の授受は本システムでは管理しません

### C-03 案件詳細 / 必要書類タブ

書類は2種類です。**収集する段階が異なります。**

| 種類 | 単位 | 収集する段階 | 表示 |
| --- | --- | --- | --- |
| 受講者別の書類（雇用契約書） | 会社の受講者ごと | ステータス7〜8 | 受講者一覧と各人の承認状況（D-04へのリンク） |
| 支給申請用の書類 | 申請案件ごと | ステータス21〜22 | 種類ごとに提出状況と承認状況 |

申請案件ごとに提出する「案件共通の書類」は設けません（5.2）。

- 必要書類の種類はコード側で固定管理し、**管理画面に追加・変更・削除機能は設けません**（5.2）
- 行が存在しない書類種別は未提出として表示します
- クライアントは提出・再提出、事務員は確認・承認を行います
- 不備の指摘は掲示板（C-08）で行います。書類ごとのコメント欄は設けません（5.12）
- 差し替えると承認が取り消され、再承認が必要になります

### C-04 案件詳細 / 契約書タブ

- 契約書はfreeeサインのテンプレートから生成します（`05_外部連携仕様.md` 3.5）
- 操作は「送付」「再送」「送付取消」の3つ
- 締結済みの契約書は取消も再送もできません
- 締結済みPDFを表示・ダウンロードできます
- **「最新状態を取得」ボタン**を配置します。締結の検知はポーリング（5〜10分間隔）のため、
  事務員がfreeeサイン側で締結を確認した直後に反映させるために使います

### C-05 案件詳細 / 見積・請求タブ

- 見積もり兼発注書と請求書を、それぞれ自動生成・送付します
- **生成しただけでは送付しません。** 送付操作を実行したときだけメールで送ります（5.9, 5.10）
- 送付先は会社情報の担当者メールアドレスです
- クライアントは署名・押印済みの見積もり兼発注書をアップロードします
- 事務員は不備がある場合、掲示板でコメントして再提出を依頼します

### C-06 案件詳細 / 予約・チームタブ

予約枠・チーム・カリキュラムを一体で表示します（5.5, 5.6, 5.7）。

- 予約枠の一覧（日程、担当講師、状態）
- 予約枠ごとのチーム（チーム名、受講者、カリキュラム）
- チームの作成は予約の後に行います。1予約枠に1チームです
- キャンセル・却下された予約に紐づいていたチームも残り、新しい予約枠へ再利用できます
- カリキュラムは研修プログラムとコースの組み合わせ132通りから1つを選択します
- **選択した時点でコース内容・講義コマ・日別割当がチームに複製されます。**
  以後マスタを変更しても、このチームの内容は変わりません（5.7）

### C-07 案件詳細 / 出欠タブ

- **全受講者を「出席」として扱うことが既定**です。出席の場合は入力しません（5.11）
- 遅刻・早退・欠席が発生した場合のみ記録します
- 記録項目は講義日・チーム・受講者・区分・備考
- 講師は自分が担当する講義日のみ、事務員はすべての講義日を登録・編集・削除できます
- クライアントは閲覧のみです
- 遅刻・早退の時刻や、受講できなかった時間は記録しません

### C-08 案件詳細 / 掲示板タブ

- 案件全体についてやり取りします。提出書類ごとの個別コメント欄は設けません（5.12）
- **未読バッジ**をタブに表示します。自分以外の新しい投稿が対象で、タブを開いた時点で既読になります
- 掲示板の投稿は共通通知（B-02）の対象外です
- 投稿者は自分の投稿を編集・削除できます
- ファイルを添付できます（PDF・JPEG・PNG・50MB）
- 代理店は閲覧のみで投稿できません（5.24）

### D-02 会社情報の登録・編集

事務員が会社を作成して会社名だけを登録し、招待されたクライアントが残りを入力します（5.3）。

- **必須項目が未入力でも一時保存できます。** 未入力のまま申請案件も作成できます
- 必須項目がすべて入力され、かつ受講者が1人以上登録されるまで、ステータスを先へ進められません
- 進められない場合は、その内容を画面に表示します
- 「契約書送付済」以降の案件が1件でもある会社では、必須項目を未入力の状態へ戻せません

入力の検証は次のとおりです。

| 項目 | 検証 |
| --- | --- |
| 法人番号 | 半角数字13桁。他社との重複不可 |
| 郵便番号 | ハイフンなし半角数字7桁。入力時に住所を自動入力（修正・手入力も可） |
| 電話番号 | 数字部分が10桁または11桁。ハイフンを許可 |
| 担当者メールアドレス | メールアドレス形式 |
| 従業員数・資本金 | 0以上の整数 |
| 業種 | 自由入力 |
| 会社形態 | 株式会社・合同会社・合資会社・合名会社・個人事業主・その他から選択 |

### D-04 雇用契約書の提出・承認

**会社単位で管理します。案件単位ではありません**（5.2）。

- 受講者1人につき1ファイル
- 承認は会社単位で一度だけ行い、同じ会社のすべての申請案件で承認済みとして扱います
- 提出対象は会社に登録されているすべての受講者で、案件やチームへの登録有無では絞り込みません
- 会社に受講者を追加した場合、その受講者の承認が済むまで進行中の全案件でステータスを進められません
- 承認済みの書類を差し替えると、**同じ会社のすべての案件で承認が取り消されます**

### E-01 講義予約の申請（クライアント）

1. 申請案件を選択する
2. 受講日数を2日間・3日間・4日間・5日間から選択する
3. 日数分の講義日と各日の開始時刻を選択する
4. システムが終了時刻を自動計算して表示する

| 受講日数 | 時間配分 |
| --- | --- |
| 2日間 | 5時間 × 2日 |
| 3日間 | 3時間 / 3時間 / 4時間 |
| 4日間 | 2時間30分 × 4日 |
| 5日間 | 2時間 × 5日 |

- 土日祝と個別休業日は選択できません
- 申請した時点で予約枠を1つ確保します（承認前でも）
- 承認前はクライアントが日時変更・キャンセルできます
- **予約申請時点ではチームを登録しません**（5.6）

### E-02 予約の承認・講師割当（事務員）

- 予約申請の一覧から承認・却下します
- **承認時に担当講師を指定します。** 指定と承認をもってスケジュールが確定します
- 同じ日時に同じ講師を重複して割り当てられません
- 同一日時の予約枠数の上限は「有効な講師数 − 1」です
- 確定時、および確定後の日時変更・キャンセル時に、クライアントと担当講師へ通知します
- **却下の場合は理由のコメントも通知も行いません**（5.5）

### G-01 / G-02 アカウント管理

| 項目 | 内容 |
| --- | --- |
| 表示列 | 利用者名・ログインID・権限（複数可）・所属会社・有効／無効・最終更新日時 |
| 検索 | 利用者名、ログインID |
| 絞り込み | 権限、有効／無効 |
| 初期表示 | 有効なアカウントのみ。作成日時の降順 |

- 事務員はシステム管理者以外を、管理者はすべてを閲覧・操作できます
- アカウント作成時にシステムが仮パスワードを自動発行します
- 再生成した仮パスワードは、メールまたはLINEで個別に伝えます（システムからは送信しません）
- 1アカウントに複数の権限を設定でき、作成後も変更できます

次の場合は操作を拒否し、理由を画面に表示します（5.4）。

- 有効なシステム管理者が1人だけのとき、そのアカウントの無効化・削除・管理者権限の解除
- 自分自身のアカウントの無効化
- 完了していない案件の主担当になっている事務員の無効化・削除・事務員権限の解除
- 今後の確定済み予約を担当している講師の削除・講師権限の解除

### G-03 お知らせ編集（管理者のみ）

- 表示のON／OFFと本文を管理します
- 装飾は太字・斜体・下線・文字色・文字サイズ、およびリンク
- 本文は最大1,000文字。画像・動画・ファイルは添付できません
- ONにする前に実際の表示内容をプレビューできます
- OFF中も内容と装飾を保持します。ONにする場合は本文が必須です
- 保存すると全画面へ即時反映されます
